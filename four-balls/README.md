# 习题2-37：四球完全弹性碰撞

由AI辅助实现。交付包含 Python 源代码和28秒、1280×720、24帧/秒的MP4视频。

[下载完整提交包](four_balls_submission.zip?raw=1) · [下载演示视频](four_balls.mp4?raw=1) · [查看源代码](four_balls.py)

## 文件
- four_balls.py：完整程序；支持MP4导出、窗口播放、物理校验。
- four_balls.mp4：可直接提交的无声动画，含中文说明、速度及碰撞进度。
- requirements.txt：Python依赖。

## 使用
建议 Python 3.9 或更高版本。

```bash
python -m pip install -r requirements.txt
python four_balls.py --check
python four_balls.py --preview
python four_balls.py --video demo.mp4
```

窗口播放需要Tkinter（部分Linux系统需安装python3-tk）；空格暂停/继续，R重播。
导出视频还需要安装FFmpeg并加入系统PATH。程序自动寻找Windows微软雅黑/黑体、macOS苹方或Linux Noto中文字体；找不到时使用 `--font 中文字体路径` 指定。
`--check` 仅使用Python标准库，无需图形依赖。

## 建模与算法

从左到右编号1至4，质量依次为2m、2m、m、m。只有1号球初速度为v，其余静止；水平面光滑，无外界水平力，球同半径，对心碰撞，恢复系数为1。

题目未给定球间距，演示取中心坐标0、3L、6L、9L，半径0.6L，速度单位v，时间单位L/v。界面t为归一化时间tv/L。间距为正且相等，碰撞依次发生。

碰撞前速度为a、b，质量为p、q，碰撞后：

u1 = ((p-q)a + 2qb)/(p+q)

u2 = (2pa + (q-p)b)/(p+q)

在相邻球接近时，根据表面间隙除以相对速度，精确计算下次碰撞时间；推进所有球到该时刻，再更新相碰两球的速度。物理计算使用Fraction有理数，画面在碰撞之间做匀速插值。没有用每帧重叠判定代替碰撞计算。

本程序针对题设初态，未扩展到任意多球同时碰撞情形。

## 计算结果

| 阶段 | 归一化时刻 | u1/v | u2/v | u3/v | u4/v |
|---|---:|---:|---:|---:|---:|
| 初态 | 0 | 1 | 0 | 0 | 0 |
| 1与2相碰后 | 1.80 | 0 | 1 | 0 | 0 |
| 2与3相碰后 | 3.60 | 0 | 1/3 | 4/3 | 0 |
| 3与4相碰后 | 4.95 | 0 | 1/3 | 0 | 4/3 |
| 2再次碰3后 | 9.00 | 0 | 1/9 | 4/9 | 4/3 |

最终速度从左到右递增，不会再碰撞。

总动量始终为2mv，总动能始终为mv²。程序验证每次碰撞的动量、动能及恢复系数，并在1201个时刻检查球体不穿透。

视频开头保持初态2秒，随后用22秒播放12个归一化时间单位的运动，末尾保持4秒。时间缩放只影响播放，物理状态取自同一精确解。
